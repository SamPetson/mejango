# mejango

a Lightweight, Flexible Data Layer for Modern Applications
Mejango is a simple yet powerful data management solution designed for developers who need an uncomplicated way to handle application data without the overhead of traditional database systems.

Key Features
Intuitive API - Work with your data using straightforward methods

Flexible Structure - Adapts to your data needs without rigid schemas

Lightweight - Minimal footprint with maximum utility

Developer-Friendly - Designed with modern workflows in mind
